# User Stories - AI-Assisted Instant Feedback Collector

## User Story 1
As a user, I want to submit feedback through a simple form so that I can share my thoughts quickly without signing up.

## User Story 2
As a user, I want to select a satisfaction rating (1-5 stars) and a visual mood indicator so that I can express my overall experience easily.

## User Story 3
As a product manager, I want to view all submitted feedback in a live dashboard grid so that I can monitor user responses in real time.

## User Story 4
As a product manager, I want to filter and search feedback by keywords so that I can identify specific feature requests or recurring issues quickly.

## User Story 5
As an admin, I want to export all feedback entries as a CSV file so that I can perform offline data analysis or import the records into external tools.

## User Story 6
As an admin, I want to see simple analytics cards (total responses, average score) at the top of the dashboard so that I can assess user satisfaction at a glance.

## User Story 7
As a user, I want to receive a visual confirmation message after submitting feedback so that I know my input was successfully recorded.

## User Story 8
As a system administrator, I want the system to enforce a limit of 100 entries so that memory usage remains efficient without needing full authentication setup.

## User Story 9
As a mobile user, I want the feedback submission page to be fully responsive so that I can submit feedback seamlessly from my phone.
